## English

### About

**DevMaster Academy** is a learning platform for web development, built around practical lessons and gamified exercises. Learners progress through topics, try code, take quizzes, and track their learning progress.

**Live demo:** [https://oquv-saytim-66ya.onrender.com/](https://oquv-saytim-66ya.onrender.com/)

### What’s included?

- Learning paths for HTML, CSS, JavaScript, TypeScript, React, backend, databases, and Full-Stack development.
- Lesson maps, explanations, code examples, in-browser practice, and quizzes.
- Test ID assessments, stage exams, and a final exam.
- Learner profiles, lesson results, XP, coins, achievements, and rankings.
- PvP challenges, streaks, rewards, a shop, and coding mini-games.
- Separate learner, teacher, and administrator workflows, plus group chat and notifications.
- AI assistance, voice responses, portfolio showcases, and feedback/bug reports.
- PDF certificates, depending on eligibility and configuration.

### Technology

React, TypeScript, Vite, Tailwind CSS, Node.js, Express, PostgreSQL, Drizzle ORM, and Firebase/Firestore integrations. AI and speech features depend on server configuration.

### Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

See `.env.example` for server configuration. Store secrets only in server environment variables; do not commit `.env` files or secret values to GitHub.
